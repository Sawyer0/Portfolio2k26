PromptShield

LLM security tooling · TypeScript CLI and Go gateway

A developer-first CLI that scans prompts, responses, and datasets for prompt injection, jailbreaks, PII leaks, and compliance violations using custom YAML RulePacks. Published to npm as @dawans/promptshield.

  • Companion Go enforcer sits behind Envoy (ext_authz and gRPC ext_proc) to inspect and redact traffic inline
  • Three-tier progressive scanner: Aho-Corasick, then regex, then LLM semantic analysis, so most requests never reach the expensive tier
  • Streaming design with constant memory regardless of payload size; NATS for live policy updates across enforcers

TypeScript · Node.js · Go · Envoy · gRPC · PostgreSQL · Redis · NATS · OpenTelemetry

  • Gateway source

Project DJA

AI Innovation Challenge, Agentic AI track · Python

A compliance-aware AI academic advisor for CUNY students. Before the model suggests any course plan, a deterministic guardrail checks it against F-1 visa, TAP, and Pell credit rules, so bad advice can't cost a student their status or aid.
